# Northstar HealthTech — Identity & Access Management Governance

**Independent IAM Governance Case Study | Educational Simulation**

## Project Overview

This project demonstrates the design of an Identity and Access Management (IAM) governance program for Northstar HealthTech, a fictional healthcare technology company with approximately 250 employees.

The case study addresses three common security governance challenges:

- Inconsistent employee onboarding, role changes, and offboarding
- Incomplete or inconsistent user access reviews
- Excessive permissions and privileged access risks

**Simulated Role:** IAM Governance Analyst

## Project Objectives

The proposed governance program aims to:

1. Standardize the employee access lifecycle.
2. Establish consistent access request and approval procedures.
3. Enforce least-privilege and role-based access controls.
4. Strengthen privileged account governance.
5. Establish periodic access certifications.
6. Track IAM risks, remediation, and leadership reporting.

## Technology Scope

- Microsoft Entra ID
- Microsoft 365
- Critical cloud applications
- Privileged administrator accounts

These technologies are included in the fictional design scenario. No production systems were configured or accessed.

## Governance Controls

The case study proposes the following controls:

- Manager approval for standard access
- Additional Security approval for privileged and sensitive access
- Account disablement at authorized employee termination time
- Quarterly standard user access reviews
- Monthly privileged account reviews
- Separate administrator accounts, multifactor authentication, and activity logging
- Risk-based remediation deadlines and monthly governance reporting
